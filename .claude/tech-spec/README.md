# tech-spec

요구사항별 테크스펙/구현 설계 문서를 이 폴더에 둔다.

- 파일명: `<날짜>-<기능명>.md` (예: `2026-07-29-order-api.md`)
- 요구사항이 주어지면 **구현 전에** 여기에 테크스펙을 작성하고, 구현·코드리뷰·PR이 모두 이 문서를 기준으로 진행된다.

## 템플릿

```markdown
# <기능명>

## 요구사항
- (주어진 요구사항 원문 또는 요약)

## API 설계
- METHOD /path — 설명, request/response 필드
- 조회 API별 미존재 처리 확정: 예외(404) / 기본값·빈 목록  ← 애매하면 구현 전에 사용자에게 확인

## 도메인/데이터 설계
- 도메인 모델, 테이블(DDL 변경 시 resources/ddl/schema.sql에도 기록)

## 구현 범위 / 제외 범위
- 이번에 하는 것 / 안 하는 것

## 엣지 케이스
- (경계 조건, 에러 시나리오)
```
